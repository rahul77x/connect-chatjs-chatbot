Technical Architecture

Where & How We Integrate With Amazon Connect

An end-to-end breakdown of the Control Plane, Data Plane WebSocket, and Contact Flow.

1

User Engagement

Visitor clicks a diagnostic chip or opens the chat widget. Frontend initiates an HTTP POST to the backend endpoint /api/start-chat.

2

Control Plane (Backend)

Backend calls Amazon Connect's StartChatContact API with the InstanceId, ContactFlowId, and customer name. Returns ParticipantToken.

3

Data Plane (ChatJS)

Frontend loads amazon-connect-chat.js. Calls connect.ChatSession.create() and opens the Participant Service WebSocket via session.connect().

4

Contact Flow & Lex Bot

Amazon Connect routes the chat to an Amazon Lex V2 Botanical Bot or Bedrock Agent, and seamlessly escalates to human agents in the queue when needed.
